Justificación

La razon por la que decidi hacer este cambio se debe a que el diseño anterior hace que todos los elementos debajo se muevan, por lo que se tiene que scrollear hasta el final de las suscripciones para poder acceder a esos elementos, con este nuevo diseño esto desaparace ya que el scroll se encapsula, permitiendo que todos los elementos se mantengan donde están y al mismo tiempo ofrecer la misma funcionalidad.
